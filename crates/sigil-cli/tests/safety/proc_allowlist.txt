# SIGIL safety harness: /proc access allowlist (contract C-6, docs/adr/ADR-002-execution-modes.md).
#
# Format:  <scope> <pattern> [ops=<op>,…]  # <reason>
# Scopes:  runtime = accesses made by SIGIL's own process runtime, allowed in every mode;
#          observe = the documented observe-mode inputs (`sigil inspect ollama --mode observe`);
#          observe_env = initial environment, only with explicit `--mode observe --observe-env`.
# Pattern: `/`-separated segments; {pid} matches digits, `self` or `thread-self`; {n} matches digits.
# Ops:     the operations an entry allows (external plan review of PR-4d-2); without `ops=`, every
#          path-taking call (only where Rust std may `statx` an open fd: `self/maps`, `boot_id`). `open` (open, openat,
#          openat2), `readlink` (readlink, readlinkat), `stat` (stat, lstat, newfstatat, statx, access,
#          faccessat, faccessat2), `list` (getdents64). A magic link (`exe`, `fd/{n}`, `ns/*`) is never
#          opened: an open would reach what it names. C-5 already refuses a write-capable open.
#
# A traced run fails on any /proc access that matches no entry of its scopes. Adding or widening an
# entry is an intentional, reviewed change: name the reading code and the plan section it serves.
runtime  /proc/self/maps        # Rust std reads the main thread's stack bounds at startup
observe  /proc/net/tcp       ops=open   # listener table (sigil-engine observe::proc; plan §4.6.8)
observe  /proc/net/tcp6      ops=open   # listener table (observe::proc; plan §4.6.8)
observe  /proc               ops=open,list   # enumerate PIDs to attribute listening sockets (observe::proc)
observe  /proc/{pid}         ops=open,list   # the process directory, opened to read its entries relative to it (observe::proc)
observe  /proc/{pid}/fd      ops=open,list   # list a process's fds to find socket inodes (observe::proc)
observe  /proc/{pid}/fd/{n}  ops=readlink   # readlink an fd to read socket:[inode], never followed (observe::proc)
observe  /proc/{pid}/comm    ops=open   # process name: selects candidates, marks fronting hints (observe::proc)
observe  /proc/{pid}/cmdline ops=open   # argv of an `ollama` process: the runtime role rests on it; the second pass reads the runtime's again, to see an exec (observe::proc; plan §4.2, PR-4d-2)
observe  /proc/{pid}/exe     ops=readlink,stat   # readlink, and stat through it for the executable's dev:ino; never opened (observe::proc; plan §4.2, PR-4d-2)
observe  /proc/{pid}/stat    ops=open   # read for every listed process: its start time (part of its identity), and its parent, to find the runtime's descendants; the second pass reads a runtime process's again, first and last, to see an exec or an exit (observe::proc; plan §4.2, PR-4d-2)
observe  /proc/{pid}/ns/net  ops=readlink   # readlink only: the network namespace, SIGIL's own and the runtime's (observe::proc; plan §4.6.8)
observe  /proc/{pid}/maps    ops=open   # the files a runtime process has mapped, read up to proc_maps_bytes (observe::proc; plan §4.6.2, PR-4d-2)
observe  /proc/{pid}/ns/mnt  ops=readlink   # readlink only: the mount namespace a mapping's path is read in, SIGIL's own and a runtime process's (observe::proc; PR-4d-2)
observe  /proc/sys/kernel/random/boot_id   # the boot the observed processes belong to, part of their identity (observe::host; plan §4.2)
observe  /proc/{pid}/cwd     ops=readlink   # selected process cwd, readlink only inside exe/stat coherence window (observe::proc::values; PR-4d-3 process values)
observe  /proc/{pid}/status  ops=open   # bounded effective uid/gid read of selected processes (observe::proc::values; PR-4d-3 process values)
observe_env  /proc/{pid}/environ  ops=open       # bounded initial environment only with --mode observe --observe-env; allowlisted minimized storage (PR-4d-3 Task 3)
