SIGIL vs other AI-BOM and model audit tools

These pages say what each tool covers, where SIGIL extends the surface, and where another tool is the right pick. Each one has a short "when to use which", a table across the same evidence axes, and a section on when SIGIL is the wrong choice.

  • SIGIL vs Anchore Syft: Syft 1.38+ catalogs GGUF models into CycloneDX ML-BOM components. Same artifact family, different evidence scope and verdict model.
  • SIGIL vs Ollama / Hugging Face built-ins: ollama show and hf cache verify verify integrity and show configuration, but emit no BOM, classify no exposure, and detect no license families.
  • SIGIL vs OWASP AIBOM Generator: OWASP's AIBOM tool generates CycloneDX 1.6 from a Hugging Face model ID. Same artifact name, different input source and integrity model.

SIGIL gives a PASS / WARN / FAIL verdict, with a completeness beside it; the three adjacent tools give no verdict.
